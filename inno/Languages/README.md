# Installer translations

`Arabic.isl` is the Arabic translation distributed by Inno Setup, retained with
its translator attribution and `RightToLeft=yes` setting.

Source: https://github.com/jrsoftware/issrc/blob/28eab5faa5d08478a2447cec3d42c3dd806c8274/Files/Languages/Arabic.isl

Keep this pinned copy in the repository so installer builds do not depend on the
languages bundled with a particular GitHub runner. Review upstream translation
changes when upgrading Inno Setup.
