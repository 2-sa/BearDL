- `Nickvision.Parabolic.WinUI/Helpers/ToggleSwitchHelper.cs` و`Views/AddDownloadDialog.xaml` و`Views/SettingsPage.xaml`: عكس رسم مفاتيح التشغيل ذات العناوين المنفصلة في العربية، مع إبقاء قالبها LTR وقيمة `IsOn` كما هي. العربية: دائرة الإيقاف يمينًا والتشغيل يسارًا؛ الإنجليزية: الاتجاه المعتاد. فُحصت ملفات XAML وفرق Git محليًا؛ يبقى التحقق البصري بعد بناء مأذون به.
- `resources/po/ar.po`: أُفرغت قيمة `translation-credits` لإخفاء أسماء المترجمين السابقين في العربية. يُسلّم التعديل مع إصلاح المفاتيح؛ لا يحتويه الإصدار 2026.5.112.
- `AGENTS.md` و`docs/RELEASING.md` وهذا الملف: تحديث إرشادات الاستمرار والتسليم للمحادثات الجديدة، ضمن الكوميت المأذون به.
- ملف `AGENTS.md` في المجلد الخارجي يوجّه المحادثة التي تبدأ من جذر مساحة العمل إلى المستودع الداخلي وهذه الملفات.
- واجهتا Windows وGNOME تتجاوزان قسم المترجمين إذا كانت القيمة فارغة أو أعاد gettext المفتاح `translation-credits`. لا تُعِد الأسماء القديمة أثناء تحديث فهارس الترجمة.
- طلب الإزالة يخص قسم المترجمين العربي الظاهر في الصورة؛ لا تحذف اعتمادات المطورين والمصممين والرسامين أو ملفات الترخيص.

## خطوات الاستمرار

1. اقرأ `AGENTS.md` وافحص `git status --short` و`git diff`؛ لا تستبدل التعديلات المحلية أو تعِدها إلى الإصدار المنشور.
2. تابع أي مشكلة جديدة يحددها المستخدم، مع الحفاظ على القيود السابقة. لا تبدأ إعادة كتابة شاملة لمجرد قراءة هذا الملخص.
3. نفّذ `git diff --check`، وتحقق من ملفات XAML المتأثرة. اجعل البناء والتغليف على GitHub عندما يأذن المستخدم بالتسليم.
4. بعد أي إذن بالكوميت أو الرفع، حدّث هذا الملخص ليطابق الحالة الفعلية والقيود السارية.
5. تحقق من النسخة المشغّلة قبل إعلان اكتمال الإصلاح البصري. `tests/windows/Verify-DownloadDialogLayout.ps1` فحص قراءة فقط لحدود صورة وتبويبات وقوائم جودة التنزيل.
